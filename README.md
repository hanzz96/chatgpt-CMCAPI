# Project Name

## Overview
This project is built using **Node.js** and **npm**. Below are the installation instructions and requirements for running the project locally.

## Specifications

- **Node.js**: 18.20.4
- **npm**: 10.7.0

## Prerequisites

Before you begin, ensure you have the following installed on your machine:

1. **Node.js** (version 18.20.4)
   - You can download it from [Node.js official website](https://nodejs.org/).
   
2. **npm** (version 10.7.0)
   - This is automatically included with Node.js, but you can update npm to a specific version using:
     ```bash
     npm install -g npm@10.7.0
     ```
